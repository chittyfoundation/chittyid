🆔 ChittyID Generator

Format: VV-G-LLL-SSSS-T-YM-C-X

VV: Version | G: Region | LLL: Jurisdiction | SSSS: Sequential | T: Type | YM: Year-Month | C: Trust | X: Checksum

L0 - Unverified
L1 - Basic
L2 - Standard
L3 - Verified
L4 - Premium
L5 - Official

API Endpoints
